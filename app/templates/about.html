En ansøgnings- og sagsportal til virtuelle undervisningsmiljøer.

Formål

Studerende og undervisere kan ansøge om en VM eller Proxmox-adgang. Administratorer kan behandle ansøgninger, registrere levering, følge op på udløb og arkivere afsluttede eller afviste sager.

Teknologi

Python, FastAPI, Uvicorn, Jinja2 og SQLite. Brugerfladen anvender lokal HTML, CSS og JavaScript uden eksterne skrifttyper, analyseværktøjer eller CDN-afhængigheder.

Afgrænsning

Version {{ version }} har ingen automatisk VM-oprettelse, adgangstildeling, sletning, e-mailafsendelse eller institutionslogin. Der foretages ingen kald til Proxmox. Systemet registrerer ansøgninger og administratorens handlinger.
